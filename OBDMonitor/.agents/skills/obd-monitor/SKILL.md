# Skill: OBD Monitor

Use esta skill em tarefas diretamente relacionadas ao aplicativo deste repositório. Ela define a sequência de consulta; as regras do projeto estão nos documentos referenciados e não devem ser duplicadas aqui.

## Fluxo de trabalho

1. Leia [README.md](../../../README.md) e as [orientações para agentes](../../../AGENTS.md) para localizar as fontes de instrução.
2. Consulte [arquitetura](../../../docs/architecture.md) e [comportamento atual](../../../docs/current-behavior.md) para identificar os componentes envolvidos e conferir os fluxos existentes.
3. Siga as convenções e os procedimentos de extensão em [desenvolvimento](../../../docs/development.md).
4. Escolha as verificações usando [verificação](../../../docs/verification.md) e relate somente o que foi realmente executado.
5. Confirme detalhes no código antes de assumir que a documentação ainda representa o comportamento atual. Se a mudança alterar o comportamento, atualize o documento que o descreve.
